# 内置 AI 解析返回空内容

`OpenAI Chat Completions 未返回文本内容` 表示提供商响应没有可用的最终文本，不等同于 PDF 损坏，也不等同于页面没有图片。没有图片的有效响应应为 `{"figures":[]}`。

内置 AI 解析逐页渲染并调用图片场景模型。任意页失败会终止本次自动解析；只有全部页面处理成功后才保存自动提取结果。手工保存的图片与自动解析状态独立。

排查时记录失败页码和完整错误提示：

- `finish_reason=length`：提供商报告输出耗尽；检查输出 token 上限和推理设置。不能将推理内容当作图片坐标。
- 过滤或拒绝：检查提供商策略和模型响应。
- 仅返回推理内容：检查模型是否产生最终答案，以及兼容接口是否正确转换响应。
- `choices` 为空或普通空响应：检查模型能力及接口兼容性，必要时在提供商侧查请求日志。

错误提示不会包含原始推理、拒绝文本或完整响应。保存手工图片会保留既有失败/取消原因，重新解析才会更新解析状态。旧版本已经覆盖的错误无法由此修复恢复。

一份 56 页、96,901,831 字节的真实 PDF 验证中，全部页面都能以 180 DPI 渲染，正文也成功提取，而数据库记录了上述空响应错误。单页重试成功，因此不能仅凭历史错误断定模型不支持图片、PDF 损坏或某页必然失败。需要保留提供商结束原因和页码来区分瞬时响应与稳定故障。
